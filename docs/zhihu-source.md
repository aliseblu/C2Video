# 知乎接入说明

当前默认：知乎官方搜索 + 本地规则口播 + Edge TTS。数据接口不再依赖旧平台会员或登录凭证。

## 官方接口

依据 2026-09-15 查阅的[知乎搜索文档](https://developer.zhihu.com/docs?key=zhihu_search)、[热榜文档](https://developer.zhihu.com/docs?key=hot_list)和[鉴权文档](https://developer.zhihu.com/docs?key=authorization)实现。

- 仅向 `https://developer.zhihu.com/api/v1/content/zhihu_search` 或 `hot_list` 发请求。
- 凭证放在 `Authorization: Bearer ...`；`X-Request-Timestamp` 为秒级当前时间。禁止跟随重定向传送凭证。
- `C2VIDEO_SOURCE_ZHIHU_ACCESS_SECRET` 只在进程配置中使用；不出现在健康接口、日志、卡片、素材或任务快照中。
- 搜索每个关键词最多请求 10 条，最多 6 个关键词，不承诺任意数量或全站搜索覆盖。
- 热榜最多取得 30 条，再本地匹配主题。未提供热度、点赞、时间或作者时，不编造这些数据。
- 保留 API 返回的原文链接及溯源参数；去重时忽略链接的查询参数。
- 401/403、额度不足、频率限制、非 JSON、未知响应结构等明确报错，不静默回退到其他平台或 Demo。
- 搜索返回的是摘要，不是整篇付费内容。默认通读已提供文字提取要点，不生成未给出的事实。
- API 权限、免费额度和费用以账号控制台为准；“密钥已配置”不代表已经验证有效。

## 在 PyCharm 配置

编辑 **C2Video Studio** 运行配置，在“环境变量”添加：

| 名称 | 值 |
| --- | --- |
| `C2VIDEO_SOURCE_ZHIHU_ACCESS_SECRET` | 自己的 Access Secret；不要截图或提交 |
| `TTS_PROVIDER` | `edge` |

FFmpeg 会自动检测字幕/文字滤镜；普通版本缺失滤镜时，自动选择已安装的 ffmpeg-full。无需修改系统 PATH。设置页会显示实际选择的二进制路径。

保存并停止旧服务后重新运行，刷新设置页确认显示“知乎官方接口”。运行任务时才会发出知乎请求。

## 无密钥导入

网页新建页选择 JSON 文件，或者 `agent run --materials /绝对路径/素材.json`。这两种方式对本次任务优先使用导入内容，即使全局配置是 API 也不调用知乎接口。

素材是 UTF-8 JSON 数组，也接受 `{"items": [...]}`；每条必填 `title` 和真实知乎原文 `url`，可填 `content`、`author`、ISO 时间 `created_at`、`voteup_count`、`comment_count`、`favorite_count`。最多 100 条、1 MB。来源仅支持问题、回答和专栏文章。

仅有标题也可导入，但生成口播时会提示缺少正文并停止，不会把标题或缺内容通知做成视频。缺失指标不作为真实的 0 展示。导入时保留原始日期，人工选定内容不受新闻时间窗口限制。重复链接只保留首条。

模板在 `examples/zhihu-materials.example.json`，故意使用无效链接占位符，必须替换后才能运行，防止示例误标为真实知乎内容。

## 兼容与边界

模型改为 `CandidateItem`，转发类字段改为中性的 `shares`，并为旧 JSON 的 `retweets` 保留只读迁移别名。知乎收藏数使用独立 `favorites` 字段，评论数不当作回答数。

已有数据库、视频、原文来源与历史技术报告不被重写。旧登录代码及旧适配器从可运行项目中移除；用户目录中的历史凭证文件不读取、不删除。原始上游署名保留。

测试需分别报告离线解析/导入回归与在线 API 验证；没有用户配置的有效密钥时，不能声称知乎在线抓取已通过。


## 短视频口播

- 默认本地模式从全部已提供文字中挑选核心结论和关键依据，去除问候、序号开场和通用收尾，不再截取正文前若干字。
- 本地使用规则式抽取摘要，不等同于大模型理解后的自由改写。它会保留完整句子、显式相邻限制和原文归因；目标时长是软预算，重要限定不因截断而丢失。
- API 模式使用模型概括和口语重写。需要单独配置模型接口；知乎 Access Secret 仅用于获取素材，不是模型密钥。本次改动不会自动启用付费模型。
- 根目录 prompts/script-prompt.md 与安装包提示词已同步；前者在项目内启动时优先读取。
- 无论哪种模式，都只基于已提供内容。接口摘要不保证覆盖原文全文；要概括完整文章，请导入有权使用的完整正文。
- 日期继续保留在卡片和发布文案中，不再自动加到每条口播的开头。已生成的历史视频和脚本不会被重写，重启服务并新建任务后生效。
