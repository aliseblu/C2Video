# C2Video 平台可靠性升级（本机实现与验收完成）

## 本轮范围

默认单机、受信小团队，Linux/macOS 本地磁盘。保留 Python、SQLite、FFmpeg 与 Studio。
不把固定 Demo 当真实模型效果，不引入多租户或分布式承诺，不自动发布视频。
公网开放、付费服务验证、数据迁移切换与停止旧进程需分别确认。

## 验收清单

- [x] 同一 Run 互斥执行；完成、取消等终态不能被旧执行者覆盖。
- [x] 后台执行请求持久排队、并发有界；进程异常留下明确失败证据而不盲目重做付费操作。
- [x] 取消与超时覆盖独立 Worker 及其子进程；暂停在步骤边界生效。
- [x] 实时 supervised/assisted 流程包含可执行审核节点；拒绝后不再生产。
- [x] 已处理记忆被 API 模型选题/写稿明确消费，仍不宣称保证语义效果。
- [x] 受保护 API、媒体和事件；登录凭证不进入 URL 或浏览器持久存储。
- [x] 配置失败不静默降级 Demo；输入约束、清晰错误响应与请求追踪。
- [x] 队列状态、服务存活/就绪、真实用量与运营说明。
- [x] 备份/恢复、部署与故障处理说明；隔离数据的回归及浏览器验收。

## 验证边界

本机后端 248 项、前端 36 项回归通过；构建、真实媒体探测、迁移副本、备份恢复和浏览器流程通过。详细证据与限制见 [验收记录](../verification/platform-2026-09-15.md)。
