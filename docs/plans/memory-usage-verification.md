# 自动记忆与用量看板验收记录

日期：2026-09-15。基于本机当前 C2Video 源码，本次是实际执行的回归与浏览器验收，不使用之前的历史通过数代替。

## 完成范围

- 用户反馈经过配置的 AI 提炼、严格校验和去重后自动保存为已启用记忆。
- 新增出处、整理说明、模型和处理器版本；支持停用与重新启用，历史原文不直接批准。
- AI 未配置、关闭、超时或输出无效时保留反馈，不回退为原文记忆。
- 新增 /usage 页面与 /api/usage 接口，统计真实请求返回的 Token、请求数、错误/取消、耗时、模型/用途、费用参考及任务/记忆概况。
- 记录格式回退等额外 HTTP 请求；未知用量保持未知，真实返回费用与按配置价格估算分开。
- 新增 SQLite llm_usage 表及索引，迁移版本为 3；没有回填旧 Demo 示例成本。
- 更新构建后的 Studio 静态文件、示例配置与使用说明。

视觉检查曾发现手机表格首列被挤成竖排，已改为表格内部横向滚动；较长时间范围的趋势默认定位到最近日期，再次构建并复验通过。

## 验证边界

- 未调用真实付费模型、未读取或写入新的真实模型密钥。
- 成功验证使用临时数据库和目录，不将模拟记录加入用户任务数据库。
- 实际供应商的语义提炼质量、usage 返回范围和费用需配置后另行验证。
- 记忆暂只写入并进入新任务上下文；本次不把偏好接入选题/口播内容生成。
- 用量采集是本地观察工具，不是强一致计费或完整供应商账单。
- 没有替用户停止正在运行的 Studio；使用新后端需重启服务。
