# C2Video 改名与验收报告

日期：2026-09-11

说明：此为 9 月 11 日的历史验收记录。9 月 15 日已进一步完成内部包名、
环境变量、数据库和启动入口的统一迁移；下文的旧名称兼容行为不再适用。

## 改名范围

- 网页名称、标识、浏览器标题、API 标题、演示视频与封面标识改为 C2Video / C2。
- Python 安装包改为 `c2video`，增加 `c2video` 命令，当时保留旧命令兼容。
- 主配置改为 `c2video.toml`，示例改为 `c2video.example.toml`。
- 支持 `C2VIDEO_` 环境变量；当时同名设置优先于旧前缀配置。
- 原有主题偏好可继续读取。
- 当时磁盘目录、内部模块和数据库文件名沿用旧路径，以兼容已有任务。
- README 与上游仓库链接明确区分：此次改动仅在本机，未发布远程仓库。

## 修复问题

1. Chrome 调试扩展会注入 `codex-agent-overlay-root`，遗留带光晕的第二个鼠标。
   为该覆盖层添加精确 CSS 隐藏规则，真实 Chrome 中确认其 `display=none`，
   截图中不再出现。正常系统鼠标与网页交互保持可用。
2. 新建任务失败时没有可见错误。现在显示错误，并恢复按钮供重试。
3. 不存在的任务一直显示载入。现在显示错误和返回总览入口。
4. 请求恢复成功后仍可能留下旧错误。现在成功加载时清除旧错误。
5. 选题原文仍套用三列网格，被压缩为逐字竖排。改为正常宽度的段落。
6. 单栏口播页面仍套用旧三栏网格。改为可读的自适应单栏布局。
7. 口播列表的兼容键处理补充 `pick_id`，避免缺少 `segment_id` 时键重复。
8. 移除质检标记条中无操作的播放按钮外观；播放通过封面按钮和原生视频控件完成。
