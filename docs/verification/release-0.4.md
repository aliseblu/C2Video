## 本次实质改动

- Docker 多阶段构建、API／Worker 独立运行、持久数据卷、健康探测、资源限制和日志轮转。
- 队列容量原子检查、低磁盘空间拒绝新工作、鉴权监控接口、生产安全响应头和更严格的请求校验。
- 修正 publish_kit 目录或文件符号链接可能越过媒体读取边界的问题。
- 修正演示／评测素材未随安装包交付的问题；容器从 /tmp 导入安装包检查资源确实存在。
- 修正备份的 SQLite 连接未关闭、WAL 临时文件进入清单导致跨进程校验失败的问题；备份快照使用独立数据库，重复校验不会更改备份。
- 安全升级 MCP 1.28.1、PyJWT 2.15.0、pytest 9.0.3 及兼容异步插件，更新前端 undici；其余前端直接依赖固定为已验证版本。
- 测试默认隔离本机配置与数据目录，修正过期版本／CLI 断言。
- 提供部署、安全、来源、运行与回滚说明，私有仓库 CI 不自动部署、不发布容器镜像。

## 数据与边界

本机 .env、c2video.toml、原 PyCharm 配置、数据库、历史媒体及个人求职分析不上传；原 PyCharm 配置中存在用户填写的凭证，因此整个 .run 被排除，改为发布无密钥模板 deploy/pycharm/C2Video Studio.run.xml。本次没有轮换用户凭证。

容器测试创建的随机命名项目与合成数据卷已清理，不涉及原工作目录。代码改动前另存本机临时备份；临时验收目录可能被系统清理，不作为长期备份。

没有验收真实供应商额度、真实模型语义质量、公网 TLS、目标服务器容量、长期稳定性或灾难恢复时间。仍采用单机 SQLite 和共享角色，不宣称分布式高可用、多租户、完整渲染沙箱、请求恰好一次或费用硬限额。公开分发／商业使用的上游授权核实事项见 NOTICE.md。
