## 本轮覆盖的失败分支

- 同一 Run 的双执行者互斥；并发入队去重与旧 claim token 拒绝。
- 取消期间工具迟到成功不会覆盖终态，不启动下一步骤。
- 暂停／恢复跳过已提交步骤；进程中断需人工确认重试，重试次数保留。
- 真实 Worker 子进程成功、审核退出、超时、取消、关闭和孤儿看门狗；拥有的进程组内后代清理。
- 审核／恢复与 Worker 退出同时发生，继续请求不会丢失。
- 实时 supervised／assisted／auto 的工具顺序、Gate 1 拒绝后无制作、Gate 2 拒绝取消。
- 审核结果物化到 Pick 输入，不仅修改 Studio 显示；审核通过后拒绝再改实时选题。
- 事务回滚、导出失败、原子文件替换失败、损坏 Ledger、显式缺失配置。
- API 模型选题和写稿获得相应范围的记忆；规则模式不调用该模型；停用不追溯改变旧任务快照。
- 模型 401／429／500 不进行格式回退请求；HTTP 错误不回显供应商响应正文。
- 媒体探测器异常会覆盖旧的“通过”报告，留下结构化问题，不显示已自动修复。
- 私有 API、媒体、SSE、Swagger／ReDoc／OpenAPI 需要登录；只读角色不能写。
- 会话撤销、密钥轮换、过期事件流关闭、登录失败限流、Host／Origin／请求大小约束。
- 恢复只写新目录，更新明确 Artifact 路径、撤销旧会话、暂停活跃 Run，不自动重放队列。

这些测试不证明外部供应商的操作恰好一次，也不等同于对任意恶意子进程的安全沙箱测试。

## 复验入口

后端测试应隔离工作目录并禁用真实配置注入，例如在一个新建临时目录下运行：

```bash
env PYTHON_DOTENV_DISABLED=1 \
  C2VIDEO_WORK_DIR=/绝对路径/独立测试目录/work \
  C2VIDEO_FINAL_DIR=/绝对路径/独立测试目录/final \
  C2VIDEO_LLM_PROVIDER=local TTS_PROVIDER=edge C2VIDEO_TTS_PROVIDER=edge \
  .venv/bin/pytest -q -p no:cacheprovider

npm --prefix studio test -- --run
npm --prefix studio run build
.venv/bin/ruff check --no-cache c2video tests scripts/verify_platform.py
```

浏览器脚本仅使用新目录，会自行隔离数据、模拟模型并启动／关闭临时服务：

```bash
C2VIDEO_QA_DIR=/绝对路径/新的浏览器验收目录 \
  .venv/bin/python scripts/verify_platform.py
```

提供了 .github/workflows/platform-ci.yml，但**没有上传或执行托管 CI**。本轮也没有在 Linux 安装 systemd／Nginx 模板。

## 未验收、不得扩大宣称的部分

- 公网 TLS、目标 Linux 加固配置与服务守护、真实机器容量和持续运行稳定性。
- 真实知乎／模型／TTS 服务的凭证、权限、费用、可用性与模型输出质量。
- 多租户、个人账号、分布式高可用、自动告警、媒体保留期清理和美元硬预算。
- 任意实时媒体错误的自动修复、事实准确性、提示注入完全防御和长期偏好效果。
- 旧版本／前台分阶段 CLI 不具有与新版后台队列相同的执行隔离保证。
- 硬崩溃后尚未提交到检查点的运行时长可能缺失，不能把 Run 时长字段作为精确计费计时器。

详见 [生产运行手册](../production-runbook.md)。本次按 context7-mcp 技能核对了框架生命周期、取消边界和 Cookie 会话行为，用于确定进程监督与访问保护的实现；未把文档核对替代实际测试。
