# 模型概括口播配置

要得到“理解内容后概括 + 口语化改写”，请使用 API 模式。本地模式是规则抽取，不能替代模型的语义改写。

## PyCharm 设置

打开“运行 → 编辑配置 → C2Video Studio → 环境变量”，新增下面四项：

| 环境变量 | 填写内容 |
| --- | --- |
| C2VIDEO_LLM_PROVIDER | api |
| C2VIDEO_LLM_API_BASE_URL | 你服务商提供的兼容 Chat Completions 的基础地址 |
| C2VIDEO_LLM_MODEL | 服务商控制台中的准确模型 ID |
| C2VIDEO_LLM_API_KEY | 你的模型密钥（只在本机填写） |

基础地址不是网页聊天地址，不要包含末尾的 /chat/completions，项目会自动追加这个请求路径。如果服务商要求 /v1 或其他前缀，基础地址必须保留它。

四项需要一起配置；只填密钥而 provider 仍为 local，不会启用模型。不要把这里的说明文字当作实际配置值。

也可以将相同变量放入项目根目录已有的 .env 文件；添加而非覆盖现有知乎凭证。请勿把密钥发到聊天、截图、提交仓库。PyCharm 的进程环境变量优先于 .env。

保存后停止并重启 C2Video Studio，刷新网页，在设置页确认“内容处理”显示“API 模型”（仅表示模式已选择，不代表连通性验证成功），然后新建任务。历史任务可能继续使用已有脚本，旧视频不会自动更新。

## 工作方式

同一个 llm 配置会用于选材和口播生成，所以切换 API 后这两步都会调用你指定的服务商，可能产生费用。知乎和配音设置不受影响。自动记忆开启后，任务反馈也会由同一模型提炼，可能额外产生调用；可用 memory.enabled=false 单独关闭。详见 [自动记忆](automatic-memory.md) 与 [用量看板](usage-dashboard.md)。

口播将读取每条素材的全部可用 body，概括为：

1. 核心观点或变化，第一句就进入主题。
2. 一至两句关键依据、原因或原文明确的影响。
3. 必须保留的条件、局限和作者观点归属。

不生成“本期看几条”开场，不念序号，不重复文章标题，不强行填满时长。根目录和安装包中的提示词已同步。

知乎接口返回摘要时，模型也只能概括摘要；要概括整篇文章，请导入有权使用的完整正文。模型输出仍需人工审稿，不能保证事实核验或自动识别所有前后矛盾。

## 验证边界

本次已用模拟模型响应验证完整正文、来源范围和提示词能传入模型路径；已用本地模式完成真实配音与视频合成。由于尚未填写你的模型配置，真实模型的连通性、输出质量和费用尚未验证。

风格检查若发现空泛开场或长段照读，会最多要求模型重写一次，因此可能额外调用接口；这不是事实核验器。模型错误会明确报错，不会自动退回到本地截取原文，以免把失败伪装成成功。
