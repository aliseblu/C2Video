# 单机容器发布边界

日期：2026-10-03。用户要求具备上线能力但不上线，并上传到其 GitHub 私有仓库。

沿用 ADR-0013 的单机共享工作空间和 ADR-0006 的不自动发布约束。新增双服务 Compose，API 与 Worker 共享本地卷；进程和存储边界不扩展到多租户或分布式。默认回环端口、生产 HTTPS 会话、非 root 容器、资源限制、队列容量和磁盘入场检查。

补充 ADR-0014：可选 MCP SDK 从 1.27.0 升至 1.28.1，以覆盖已知安全修复，工具语义和人工审批边界保持不变；需要经过传输与工具回归，不直接跨到 SDK v2。测试框架因安全修复升级至 pytest 9 与兼容的 pytest-asyncio 1.x。

发布验证分层：业务回归、真实本地媒体、浏览器、Linux 容器、备份恢复和公开漏洞库审计。源码包含 CI，但测试通过不等于供应商联网、生产 TLS、容量和长期稳定性已验收。基础镜像固定摘要，应用依赖固定版本；无 wheel 哈希和 Debian 快照，不声称完全可复现。

上线运维步骤保存在 docs/container-deployment.md。当前不申请服务器、不修改 DNS、不公开代码或容器镜像。
