# 单机平台可靠性与访问边界

日期：2026-09-15。状态：实现并进行本机验收，尚未部署到目标生产环境。

## 授权与范围

用户要求升级为生产级 Agent 平台，并选择个人／小团队单机部署，优先可靠性与安全闭环；另行允许改动存储、运行时、API 与 Studio。
继续采用 SQLite、有限状态机、Tool Registry 和明确工具边界，不引入分布式队列、多租户或任意代码执行。
沿用 ADR-0006：平台只生成发布包，不自动发布到社交平台。

## 决策

1. RunQueue 将执行请求持久化；一个数据库只允许一个 Supervisor，并发限制为 1–4。Run 使用本机操作系统文件锁排他执行，锁随进程退出释放。
2. API 与执行进程分离。生产请求只能排队，由独立进程执行；Supervisor 管理其拥有的进程组，取消／超时／关闭时终止。Worker 看门狗检测父进程消失和取消。暂停在步骤边界生效。
3. 结果、任务检查点、计费摘要和完成事件以短事务提交；终态不被迟到成功覆盖。SQLite 是事实来源，JSONL 仅是提交后的尽力导出。外部操作无法承诺 exactly-once：不确定的中断标为失败，人工检查后确认重试。
4. 创建请求支持幂等键，启动请求去重。审核／恢复与 Worker 退出竞态通过再次排队处理，不丢失继续请求。
5. 实时流程是 fetch → curate → Gate 1 → card → script → render → 实际媒体检查 → Gate 2。supervised 两次审核，assisted 仅第二次，auto 跳过审核但不跳过媒体检查。审核数据库决策会物化为后续卡片／写稿输入；实时就地改稿尚未实现，明确拒绝。
6. 共享操作员／只读密钥换取可撤销的会话。密钥不进入 URL 或浏览器持久存储；会话以摘要保存，使用 HttpOnly、SameSite=Strict，production 强制 Secure。API、文档、媒体与 SSE 均受保护，SSE 持续检查会话是否有效。无密钥只允许开发环境回环地址访问。
7. Host／Origin 白名单、JSON 请求大小与读入时间限制、登录失败限流、请求编号与不回显请求体的错误响应构成基本入口防护。生产浏览器卡片阻断外部资源加载；没有实现容器／租户级安全沙箱。
8. 已验证依赖版本保存为 constraints-platform.txt，前端沿用 package-lock.json。部署文件是模板，不代表 Linux 服务、TLS 或供应商已验收。
9. 备份要求停止所有写入者，SQLite backup 与文件校验和共同保存；恢复只允许新目录，撤销旧会话、暂停活跃任务，不自动重放队列。

## 对既有 ADR 的显式扩展

**取代 ADR-0012 决策第 6 条“本次不改选题、写稿”的范围限制**：新任务将最多 10 条已启用且经过 AI 处理的偏好冻结为带来源 ID 的 memory_preferences，API 选题／写稿按 scope 消费。旧 memory_context 保留兼容，但未经 AI 整理的内容不进入此新消费通道。停用影响后续任务；visual／quality 偏好暂未接入媒体生成。结构测试不等于真实模型效果保证。

扩展 ADR-0010 的有界运行时：新增单机守护与真实审核节点，未把固定计划包装成自主多 Agent 推理。历史 Run 保留原计划，新门禁用于新建实时 Run。

## 不能据此声称

- 分布式高可用、多租户数据隔离、个人账号审计、SSO 或沙箱执行。
- 外部请求恰好一次、提示注入完全防御、模型事实准确、自动记忆语义无误。
- Token 完整覆盖或美元硬预算：未知用量不填零；费用看板是记录／估算，不是供应商账单或消费限额。
- 任意实时媒体缺陷自动修复：当前真实 QC 失败会阻断并留下问题，Demo 的固定修复不能算通用生产修复。
- 通过测试等于线上长期稳定。上线前条件见生产运行手册。
